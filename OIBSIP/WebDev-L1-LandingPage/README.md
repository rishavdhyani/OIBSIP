# SkyTrail — Travel Landing Page

**Oasis Infobyte Web Development Internship | Level 1 — Task 1**

A clean, beginner-friendly and responsive landing page for a fictional travel inspiration brand called **SkyTrail**. Built with HTML5 and CSS3, without JavaScript.

## Tech stack

- HTML5
- CSS3 (Flexbox, Grid, media queries, custom properties)
- Google Fonts (DM Sans and Manrope)
- Unsplash image URLs for decorative photography
