# SkyTrail — Travel Landing Page

**Oasis Infobyte Web Development Internship | Level 1 — Task 1**

A clean, beginner-friendly and responsive landing page for a fictional travel inspiration brand called **SkyTrail**. Built with HTML5 and CSS3, without JavaScript.

## Features

- Sticky navigation bar with Home, Features, About, Stories and Get Started links
- Hero section with headline, supporting text and calls to action
- Three feature cards
- About section with a mountain photograph
- Travel quote section
- Contact call-to-action and footer with placeholder social links
- Consistent colour palette and readable typography
- Responsive layout for desktop, tablet and mobile
- CSS-only mobile navigation menu
- Smooth scrolling and hover effects
- Accessible navigation labels and descriptive image alt text

## Tech stack

- HTML5
- CSS3 (Flexbox, Grid, media queries, custom properties)
- Google Fonts (DM Sans and Manrope)
- Unsplash image URLs for decorative photography

## Run locally

1. Download or clone the repository.
2. Open `OIBSIP/WebDev-L1-LandingPage/`.
3. Double-click `index.html` to open it in your browser.
4. For live reload while editing, open the folder in Visual Studio Code and use the Live Server extension (optional).

An internet connection is needed to load the Google Fonts and remote Unsplash photographs. The layout and content remain available if those services cannot load.

## Customisation

- Change the brand name and page copy in `index.html`.
- Update colours in the `:root` section at the top of `style.css`.
- Replace the image URLs with your own photographs if desired.
- Replace `hello@example.com` and social links with your own details before publishing. These are placeholders, not real contact details.
