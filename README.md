# Tempora — Temperature Converter

**Oasis Infobyte Web Development Internship | Level 1 — Task 3**

A responsive temperature conversion tool built with HTML5, CSS3, and vanilla JavaScript. It converts a selected input unit into Celsius, Fahrenheit, and Kelvin simultaneously.
